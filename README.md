# The Remote Bible · La Biblia del Remoto

The reference manual for working without borders, from **ActiveXRemote · The Remote Business School**.

Two overviews, one system: the founder who builds the remote company, and the worker — contractor or EOR — who makes it run. Plus a shared apparatus for measuring performance: KPIs, reports, and how they tie to company objectives. This is a **living document**: edit the Markdown, commit, and the campus version follows.
