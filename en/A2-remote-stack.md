# Appendix · The essential remote stack

Fewer tools, used better. One per function: duplicating tools duplicates confusion. This is the minimum stack a remote company runs on — the key pieces, not a catalog of everything out there.

| Function | Tool | For what |
|---|---|---|
| Source of truth and docs | Coda | The handbook, decisions, and processes in one place. |
| Async communication | Slack | The day-to-day, in writing, by channel. |
| Video | Google Meet | The synchronous stuff, only when writing won't do. |
| Async video | Loom (loom.com) | Record your screen and send a short video instead of a meeting. |
| Meeting notes | Granola | So what's said gets written without effort. |
| Work management | Linear / Asana | Tasks and projects with an owner and a status. |
| Job board | Remote and Talent · Indeed (indeed.com) | Post the opening and receive candidates. |
| Hiring remote talent | **Hirem0** (hirem0.com) | Find and hire remote talent. |
| Video interviews | Hireflix | Candidates record their answers; you review them when you can. |
| Global contracts and pay | **Deel** (deel.com) | Contractors and EOR in one place; payroll and taxes. |
| Multi-currency payout (worker) | Wise / Revolut | Get paid without losing on FX. |
| Nomad insurance | SafetyWing | Health coverage across countries. |
| Security | 1Password | Password manager and two-factor. |

**How to use it:** pick one tool per function and write it into your company handbook (see appendix A1). The rest is noise. Switching a tool is expensive; switching three at once is impossible.
